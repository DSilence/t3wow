T3 Code environment

In T3 Code, open Settings › Connections, open the environment's menu and choose Copy MCP URL. T3 Connect, Tailscale and LAN addresses all work.

Approve the bridge in your browser: enter a pairing code from the host (Settings › Connections) and choose Supervised or higher to send messages from the game.

World of Warcraft

The addon goes into each game folder you tick. Restart the game after a change.

    World of Warcraft is running: close it to change the addon.

    Live updates

    How many times per game session the addon can pick up new data without reloading the UI. When they run out, Sync reloads the UI once and starts over.

    Voice dictation

    Hold the shortcut while you speak, or tap it to start and tap again to stop. The words go into the T3 window's message box in game, for you to check and send. The shortcut only works while the game runs.

    Shortcut
    Language A language tag like en-US or de-DE; empty uses the system language.
